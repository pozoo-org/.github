# Pozoo · 破竹

我们为外贸团队开发获客软件。从产品资料、目标市场和买家画像出发，在地图上找到潜在买家，按公司业务和匹配度筛选，整理成销售团队可跟进的名单。

[查看产品预览](https://prospecting-site.shanechang.workers.dev/)

## 产品进展

| 产品 | 当前进展 |
| --- | --- |
| **Leadwork 桌面版** | 支持 macOS 和 Windows 试用。可按买家画像和匹配度筛选并导出线索，任务和结果保存在本机。 |
| **云端工作台** | 正在开发浏览器端的获客和线索管理。 |

试用成员可在对应版本下载安装包并查看使用指南。 [Leadwork 试用版](https://github.com/pozoo-org/prospecting-desktop/releases)
